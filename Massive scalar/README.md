# Massive scalar test

A separate test of the complex-contour method on the massive scalar (Klein–Gordon / screened Poisson) toy model.
Independent of `Claude Implementation/`, which is the massless scalar test and is not modified here.

- `Mathematica/`: the implementation (its own copy of what it needs from the massless package; nothing imported in place).
- `figures/`: vector PDFs with CSVs.
- `note/`: the LaTeX write-up, `massive-scalar-test.tex` / `.pdf`.
- `results/`: CSV tables, summaries, check lists and logs.
